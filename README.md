# ColorOSCC 1.1 — Центр управления ColorOS 16 для iOS 15–17 (только rootless)

Сборка: `make package FINALPACKAGE=1` (или GitHub Actions: Actions → Artifacts).
Зависимости на устройстве: preferenceloader.

Настройки: Настройки → ColorOSCC (масштаб шторки, размер круглых кнопок, подписи).
Правка кнопок: карандаш → кнопки трясутся; «−» убирает, «+» из нижнего лотка добавляет, удержание и перетаскивание меняет порядок. Галочка — готово.

Не проверено на устройстве (приватные API): режим вибро/без звука, «Не беспокоить», запись экрана, скриншот.
